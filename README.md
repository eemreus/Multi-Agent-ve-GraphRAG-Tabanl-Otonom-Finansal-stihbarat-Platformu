# Multi-Agent-ve-GraphRAG-Tabanl-Otonom-Finansal-stihbarat-Platformu
Finansal OSINT ve kurumsal istihbarat için geliştirilmiş, çoklu ajan (Multi-Agent) tabanlı otonom araştırma platformu. Web kaynaklarını ve KAP bildirimlerini tarayarak karmaşık verileri Neo4j tabanlı bilgi grafiğine dönüştürür; standart vektör RAG yerine GraphRAG kullanarak çok adımlı, yüksek doğruluklu analizler sunar.
